## 👋 About Me

블록체인 · 커머스 · 의료 도메인을 두루 경험한 **풀스택 개발자 이성현**입니다.

- 🏥 현재 **씨엠병원 전산과**에서 백엔드/서버 개발을 하고 있습니다 (5개사 · 3년 10개월+)
- 🔄 서비스 기획 → 데이터 설계 → 백엔드 API → 프론트엔드 → 운영까지 **전 과정**에 참여해왔습니다
- 🧭 기술 자체보다 **비즈니스 문제 해결**에 집중하고, 새로운 도메인에 빠르게 적응합니다
- 🤖 **Claude Code 기반 AI 페어 프로그래밍**을 실무 워크플로우로 정착시켜 사용 중입니다 — MCP 서버 설계, Hooks/커맨드 하네스 엔지니어링, ADR 기반 의사결정 문서화
- ✍️ 명확하고 이해하기 쉬운 코드와 문서를 지향합니다
